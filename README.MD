## Как пользоваться

1. Откройте файл своей роли и закройте перевод.
2. Ответьте на вопрос вслух по-английски, как на интервью: одна-две минуты.
3. Сверьтесь с переводом — так ли вы поняли вопрос.
4. Посмотрите пример ответа и разбор структуры на странице роли и повторите ответ своими словами.

В каждом файле первый вопрос раскрыт полностью — с примером ответа и разбором. Остальные ответы лежат на сайте: [вопросы на собеседовании на английском по ролям](https://brolango.ru/voprosy-na-sobesedovanii?utm_source=github&utm_medium=repo&utm_campaign=interview-questions).

## Откуда вопросы

Подборку ведёт [BroLango](https://brolango.ru/?utm_source=github&utm_medium=repo&utm_campaign=interview-questions) — сервис для английского под профессию и подготовки к собеседованиям. Темы собраны по открытым подборкам вопросов для каждой роли, формулировки и переводы написаны заново и проверены вручную. Это не вопросы конкретных работодателей.

## Как помочь

* Нашли ошибку в формулировке или переводе — откройте issue или пришлите pull request.
* Не хватает роли — напишите в issue, какой именно; новые роли добавляются пачками.
* Вопрос, который вам задали на реальном интервью, тоже можно предложить через issue — без названия компании.
* Буду рад звездочке на эту репу. Вы очень поможете продвижению проекта
